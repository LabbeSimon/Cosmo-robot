# Third-party code and data

Apart from the Gradle wrapper (`gradlew` and `gradle/wrapper/`, Apache-2.0,
generated by Gradle and used only to build), this repository contains no
third-party file. The built app does contain third-party code: at build time,
Chaquopy installs pycozmo and its dependencies from their published packages and
packs them, with the Python runtime, into the APK. What follows is everything
that ends up inside it, and under which licence.

## Python packages in the APK

Where a version is pinned, it is in `app/build.gradle`.

| Package | Role | Licence |
|---|---|---|
| [pycozmo](https://github.com/zayfod/pycozmo) 0.8.0 | Cozmo protocol, the whole robot side | MIT |
| [NumPy](https://github.com/numpy/numpy) | audio and image processing, pycozmo dependency | BSD-3-Clause |
| [Pillow](https://github.com/python-pillow/Pillow) | camera frames and screen images, pycozmo dependency | MIT-CMU (historically called HPND) |
| [dpkt](https://github.com/kbandla/dpkt) | packet parsing, pycozmo dependency | BSD-3-Clause |
| [flatbuffers](https://github.com/google/flatbuffers) | serialisation, pycozmo dependency | Apache-2.0 |

## Android

The interface uses only the Android framework: no AndroidX, no Google Play
services, no analytics or advertising library.

## Anki's resources

Anki's original robot assets — animations, sounds, face data. These belong to
Anki (now Digital Dream Labs) and are **not** redistributable. Neither this
repository nor the app contains them. The planned animation feature will
download them on first launch, from their own source, the way pycozmo has
always done. Without them everything works except animations.

## App icon

The launcher and store icons are derived from
[Forklift Diskette](https://www.svgrepo.com/svg/142221/forklift-diskette) on
SVG Repo: the parcel is removed, the remaining hand truck is recoloured and
scaled to Android's adaptive icon safe zone. Licence: as stated on that page.
